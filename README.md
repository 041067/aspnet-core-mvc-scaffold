# ASP.NET Core MVC Scaffold

Este projeto tem como objetivo demonstrar, de forma prática e organizada, a utilização da arquitetura **MVC (Model-View-Controller)** no **ASP.NET Core**, utilizando **Scaffold** para a geração automática de Controllers e Views, integrado ao **Entity Framework Core**.

O repositório foi desenvolvido com foco **educacional**, servindo como material de estudo, referência técnica e apoio para desenvolvedores que estão aprendendo ou revisando os conceitos fundamentais do ASP.NET Core MVC.

---

## 🎯 Objetivo do Projeto

- Demonstrar a arquitetura MVC na prática
- Apresentar o uso do Scaffold no ASP.NET Core
- Implementar um CRUD completo com Entity Framework Core
- Facilitar o entendimento do fluxo entre Models, Controllers e Views
- Servir como base para estudos, aulas e projetos acadêmicos

---

## 🛠️ Tecnologias Utilizadas

- ASP.NET Core MVC
- Entity Framework Core
- Scaffold (Controllers e Views)
- Razor Views
- SQL Server (ou outro provedor configurável)
- .NET SDK
